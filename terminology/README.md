# Placeholder terminology

This seed is a placeholder subset for the prototype. Production terminology must come from a versioned, signed bundle. All seed labels are unverified and are not authoritative until checked against the WHO ICD-10 release.

The supplied chapter markers are preserved as data; they are not validated as WHO chapter identifiers. Exact diagnosis matches and case-sensitive prefix matches retain the dot. No dot stripping, case conversion, code inference or silent remapping occurs.
